# Breast cancer subtype classification from TCGA RNA-seq

Can you tell a breast tumor's PAM50 molecular subtype (LumA, LumB,
HER2-enriched, Basal-like) from bulk RNA-seq alone? Short answer: yes,
pretty well — and the interesting part isn't the accuracy, it's *where*
the model gets confused and how few genes you actually need.

## Data

- **Expression:** TCGA-BRCA RNA-Seq V2 RSEM, 1100 samples, via cBioPortal's
  `brca_tcga` study. I originally wanted this from UCSC Xena's GDC hub, but
  their S3 download links return HTTP 403 (checked Sep 2026), so I fell back
  to cBioPortal's public datahub — same underlying TCGA data.
  https://www.cbioportal.org/study/summary?id=brca_tcga
- **Labels:** PAM50 subtype calls from `brca_tcga_pub`, the 2012 TCGA breast
  cancer paper cohort (Cancer Genome Atlas Network, *Nature* 2012).
  521 samples had labels; Normal-like had only 8, so I dropped it — 513
  samples across 4 subtypes (LumA 231, LumB 127, Basal 98, HER2 58).
  https://www.cbioportal.org/study/summary?id=brca_tcga_pub

## Methods

log2(RSEM+1), top 3000 genes by variance, then three sklearn models —
multinomial logistic regression, random forest (300 trees), histogram
gradient boosting — each in a `Pipeline(StandardScaler, clf)` so the scaler
is fit inside every CV fold. Stratified 80/20 split (seed 42), 5-fold CV on
train, final numbers on the held-out test set. Class-weighted, except HGB:
with class weights each HGB fit took ~5x longer and 5-fold CV became
impractical, so it runs unweighted (imbalance is moderate; macro-F1 keeps
the comparison honest).

Two extra experiments:
- **05_gene_panel.py** — rank genes by ANOVA F on train only, retrain
  logistic regression on the top 50/20/10 (etc.) genes. Clinical angle: a
  3000-gene signature isn't an assay; a 50-gene one could be.
- **04_interpret.py** — top genes per model plus a misclassification
  analysis on the row-normalized confusion matrix.

## Key findings

1. **Gradient boosting wins.** Test accuracy 0.893, macro F1 0.908, OvR AUC
   0.981 — ahead of logistic regression (0.864 / 0.867 / 0.972) and random
   forest (0.845 / 0.864 / 0.968).
2. **The LumA/LumB boundary is the hard part.** 19% of true LumB tumors get
   called LumA and 11% of LumA get called LumB. That's exactly what you'd
   expect — both are ER+, separated mostly by proliferation — and it's the
   known clinically tricky distinction, not a model artifact.
3. **You barely need 3000 genes.** A 50-gene panel keeps 0.806 accuracy (vs
   0.864 full); 500 genes actually *beats* the full panel (0.874 vs 0.864),
   probably by cutting noise. The 50-gene list is in
   `results/panel_top50_genes.csv`.
4. **Sanity check passes.** Random forest's top genes include ESR1, FOXA1,
   and MLPH — the textbook luminal markers. If those hadn't shown up I'd
   have questioned the whole pipeline.
5. **Basal is the easy call** (recall 1.00), LumB the hardest (0.81) —
   consistent with finding 2.

## Results

| model | CV accuracy | test accuracy | test macro F1 | test OvR AUC |
|---|---|---|---|---|
| logistic regression | 0.824 ± 0.012 | 0.864 | 0.867 | 0.972 |
| random forest | 0.822 ± 0.018 | 0.845 | 0.864 | 0.968 |
| hist. gradient boosting | 0.844 ± 0.014 | **0.893** | **0.908** | **0.981** |

Gene panel (logistic regression, same split):

| panel size | test accuracy | test macro F1 | test OvR AUC |
|---|---|---|---|
| 3000 | 0.864 | 0.867 | 0.972 |
| 500 | 0.874 | 0.888 | 0.969 |
| 100 | 0.806 | 0.812 | 0.952 |
| 50 | 0.806 | 0.803 | 0.957 |
| 20 | 0.748 | 0.768 | 0.914 |
| 10 | 0.689 | 0.731 | 0.910 |

Figures and full per-class numbers: `results/` (`metrics.json` has everything).

## How to run

```bash
pip install -r requirements.txt
python3 src/01_download.py      # ~195 MB into data/raw/
python3 src/02_preprocess.py
python3 src/03_train_evaluate.py
python3 src/04_interpret.py
python3 src/05_gene_panel.py
```

Scripts run top to bottom; each one logs what it's doing. Seeds are fixed
(`src/config.py`), so results reproduce.

## Repo structure

```
src/
  01_download.py        fetch RSEM + clinical files from cBioPortal
  02_preprocess.py      log2 transform, PAM50 labels, variance filter
  03_train_evaluate.py  3 models, 5-fold CV, test metrics, figures
  04_interpret.py       top genes, marker check, misclassification analysis
  05_gene_panel.py      minimal gene panel experiment
  config.py, utils.py
results/                metrics.json + figures (committed)
data/                   raw + processed data (gitignored, regenerated by 01/02)
```
